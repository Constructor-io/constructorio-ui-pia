# Constructor AI Product Insights Agent UI

A React widget that answers shoppers' questions on a product page. It handles the requests, the rendering and the tracking.

```bash
npm install @constructor-io/constructorio-ui-pia
```

## How these docs are organised

- **Guides** show how to do something. Start with the [Integration Guide](./?path=/docs/guides-integration-guide--docs).
- **Components & Utilities** is the reference for everything the package exports: every `CioPia` prop, and the helper functions.

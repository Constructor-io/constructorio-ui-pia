# Integration Guide

Steps 1–2 are all you need. Everything after is optional, and each step links to its own guide.

## 1. Install

```bash
npm install @constructor-io/constructorio-ui-pia
```

Requires Node.js >= 20, and React and React DOM >= 16.12.0.

## 2. Render on the product page

`apiKey`, `itemId` and `itemName` are required.

```jsx
import { CioPia } from '@constructor-io/constructorio-ui-pia';
import '@constructor-io/constructorio-ui-pia/styles.css';

export default function ProductPage({ itemId, itemName }) {
  return <CioPia apiKey='YOUR_API_KEY' itemId={itemId} itemName={itemName} />;
}
```

<Canvas of={DisplayConfigsStories.Default} />

Not using React? Use the bundle. It takes every `CioPia` prop, plus `selector` and `includeCSS` (default `true`):

```js
import CioPia from '@constructor-io/constructorio-ui-pia/constructorio-ui-pia-bundled';

CioPia({ selector: '#pia-container', apiKey: 'YOUR_API_KEY', itemId: 'PRODUCT_ITEM_ID', itemName: 'Product name' });
```

# Checkout

Pass `checkoutTriggers` to render checkout buttons inside the PIA widget, so a shopper can buy straight from the answer.

Triggers render in `default` and `conversation` modes and in the modal, below the answer. `recommendations` mode ignores the prop.

PIA renders the buttons and nothing else. The checkout flow, and where it renders, is yours.

## Setup

The example uses [`@constructor-io/constructorio-ui-checkout`](https://github.com/Constructor-io/constructorio-ui-checkout), which is recommended but optional.

```bash
npm install @constructor-io/constructorio-ui-checkout
```

```tsx
import { CioPia } from '@constructor-io/constructorio-ui-pia';
import {
  CioCheckoutProvider,
  CioCheckoutStep,
  CioStripePaymentStep,
  CioFulfillmentStep,
  PAYMENT_STEP,
  useCioCheckout,
} from '@constructor-io/constructorio-ui-checkout';

// 1. Mount the provider once at your app root.
export default function App() {
  return (
    <CioCheckoutProvider
      provider='stripe'
      steps={[{ id: PAYMENT_STEP }, { id: 'complete' }]}
      onCreateSession={async (state) => {
        const res = await fetch('/api/checkout-session', {
          method: 'POST',
          body: JSON.stringify({ items: state.cartSnapshot }),
          headers: { 'Content-Type': 'application/json' },
        });
        return res.json(); // { clientSecret, publishableKey }
      }}>
      <ProductPage />
      <CheckoutModal />
    </CioCheckoutProvider>
  );
}

// 2. Start the flow from a trigger.
function ProductPage() {
  const flow = useCioCheckout();

  return (
    <CioPia
      apiKey='YOUR_API_KEY'
      itemId='prod_123'
      itemName='Wireless Headphones'
      checkoutTriggers={[
        {
          id: 'buy-one',
          label: 'Buy Now — $129',
          onTrigger: () => {
            flow.setCart([
              { id: 'prod_123', name: 'Wireless Headphones', unitAmount: 12900, quantity: 1 },
            ]);
            flow.start();
          },
        },
      ]}
    />
  );
}

// 3. Render the active checkout — modal, inline, or a route.
function CheckoutModal() {
  const flow = useCioCheckout();
  if (flow.state.currentStepId === null) return null;
  return (
    <Modal onClose={() => flow.clearState()}>
      <CioCheckoutStep id={PAYMENT_STEP}>
        <CioStripePaymentStep />
      </CioCheckoutStep>
      <CioCheckoutStep id='complete'>
        <CioFulfillmentStep
          onFulfill={() => fetch('/api/verify-order').then((res) => res.json())}
        />
      </CioCheckoutStep>
    </Modal>
  );
}
```

## `CheckoutTrigger`

One entry per button. Add more for parallel paths (Buy 1 / Buy 2, save 25%).

```ts
type CheckoutTrigger = {
  id: string;
  label?: string;
  disabled?: boolean;
  triggerWhen?: (state: CioPiaRenderProps) => boolean;
  renderButton?: (props: {
    onClick: () => void;
    label: string;
    disabled?: boolean;
    id: string;
  }) => ReactNode;
  onTrigger: (state: CioPiaRenderProps) => void;
};
```

<Markdown>
  {`
| Prop | Required | Description |
|------|----------|-------------|
| \`id\` | yes | Stable identifier. Used as the React key and passed to \`renderButton\` |
| \`onTrigger\` | yes | Fires on click with the current render-props snapshot — seed the cart and start your flow here |
| \`label\` | no | Button text. Defaults to \`"Checkout"\` |
| \`disabled\` | no | Disables the button, and is passed through to \`renderButton\` |
| \`triggerWhen\` | no | Re-evaluated every render; return \`false\` to hide the button. Defaults to always visible |
| \`renderButton\` | no | Replaces the default button. Receives \`{ onClick, label, disabled, id }\`; styling becomes yours |
`}
</Markdown>

```tsx
// Hide until an answer has been shown — works in every mode.
triggerWhen: (state) => !!state.currentAnswer;

// Conversation mode and the modal also fill conversationHistory, so you can
// gate on depth there. It stays empty in default mode.
triggerWhen: (state) => state.conversationHistory.length >= 2;

// Use your own button.
renderButton: ({ onClick, label, disabled }) => (
  <MyButton onClick={onClick} disabled={disabled}>
    {label}
  </MyButton>
);
```

PIA does not reset your checkout flow — call `flow.clearState()` from your own close handler.

For the full checkout API, see the [Constructor.io Checkout Library](https://github.com/Constructor-io/constructorio-ui-checkout).

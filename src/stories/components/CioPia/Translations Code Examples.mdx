# Translations (i18n)

The translations feature allows you to customize all UI text strings in the PIA component to support internationalization (i18n).
All translation keys are optional - any key you do not provide falls back to the English default.

> **Important Note:** Translations only apply to hardcoded UI strings within the library (e.g., "Any questions about this product?", "Ask anything", "Send", etc.).
> They do **not** translate dynamic content from the API response, such as:
>
> - Suggested questions
> - AI-generated answers
> - Product names, descriptions, and other catalog data
>
> API response content should be translated on your backend or through Constructor.io's dashboard configuration.

## Available Translation Keys

All keys are optional. A key you omit falls back to the English default.

An **empty string is used as-is**, which is how a visible string is hidden. Note
that the keys marked below as accessible names have no visible counterpart, so
blanking one of those leaves the control with no name for screen reader and
voice-control users - omit the key instead of setting it to `''`.

```typescript
{
  // Title
  "Any questions about this product?": "...",

  // Input
  "Ask anything": "...",

  // Send button
  "Send": "...",

  // Disclaimer
  "AI-generated answers aim to help, but they may occasionally miss details or be inaccurate. Double-check important information before purchasing.": "...",

  // Feedback
  "Is this answer useful?": "...",

  // Learn more link
  "Learn More.": "...",

  // Ask about this product
  "Ask about this product": "...",

  // Product card action
  "Add to Cart": "...",

  // Shown when a request fails without a message of its own
  "Unexpected error": "...",

  // Accessible name for the icon-only modal close button
  "Close": "...",

  // Error retry button (visible label and accessible name)
  "Retry": "...",

  // Accessible names for the feedback buttons
  "thumbs up": "...",
  "thumbs down": "...",

  // Accessible name of the question field when "Ask anything" is blanked to hide the placeholder
  "Your question": "...",

  // Accessible name for the conversation history region
  "Conversation history": "...",

  // Announced to screen readers while loading
  "Loading answer": "...",

  // Announced once the answer has arrived
  "Answer ready": "..."
}
```

## Basic Usage

Only a few keys are shown here - see the Spanish example above for a complete
translations object.

```jsx
import { CioPia } from '@constructor-io/constructorio-ui-pia';
import '@constructor-io/constructorio-ui-pia/styles.css';

const DEMO_API_KEY = 'YOUR_API_KEY';
const DEMO_ITEM_ID = 'YOUR_ITEM_ID';

export default function MyComponent() {
  return (
    <CioPia
      apiKey={DEMO_API_KEY}
      itemId={DEMO_ITEM_ID}
      displayConfigs={{
        showFeedback: true,
        learnMoreUrl: 'https://constructor.io/learn-more',
      }}
      translations={{
        'Any questions about this product?': '¿Alguna pregunta sobre este producto?',
        'Ask anything': 'Pregunta lo que quieras',
        Send: 'Enviar',
        'AI-generated answers aim to help, but they may occasionally miss details or be inaccurate. Double-check important information before purchasing.':
          'Las respuestas de IA pueden no ser siempre precisas.',
        'Is this answer useful?': '¿Es útil esta respuesta?',
        'Learn More.': 'Más información.',
        'Ask about this product': 'Pregunta sobre este producto',
      }}
    />
  );
}
```

## Partial Translations

You can override only specific strings. Any key not provided will use the English default:

```jsx
<CioPia
  apiKey={DEMO_API_KEY}
  itemId={DEMO_ITEM_ID}
  translations={{
    'Any questions about this product?': 'Got a question? Ask our AI assistant!',
  }}
/>
```
